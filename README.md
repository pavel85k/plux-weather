# Plux Weather

Версия: `1.0.0`

Локальное погодное приложение для Windows на Python. Показывает текущую погоду из Open-Meteo, определяет примерное местоположение по IP, сохраняет настройки и историю температуры в `%LOCALAPPDATA%\Plux` и обновляет данные каждые 5 минут, пока приложение запущено.

Приложение запускается обычным видимым окном и закрывается кнопкой закрытия окна. Оно не устанавливается в автозагрузку и не перехватывает глобальные клавиши. Для Windows-уведомлений установите зависимости из `requirements.txt`.
